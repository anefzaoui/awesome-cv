## 🛠️ Resume Builders

🏆 **[MobileCV.ai](https://mobilecv.ai)** — *⭐ Featured*

> AI-powered resume builder that turns any document (PDF, Word, image) into a beautiful, ATS-optimized resume in seconds. Supports LaTeX-style outputs, multiple templates, instant downloads.
> **🆓 🌐 🤖 💼**

* [Reactive Resume](https://rxresu.me) — Open-source, privacy-first resume builder with customizable themes and JSON import/export. **🟢 🆓 🌐 🛠**
* [FlowCV](https://flowcv.com) — Modern resume builder with sleek templates, instant previews, and unlimited free downloads for your first resume. **🆓 🌐 💼**
* [OpenResume](https://www.open-resume.com) — Browser-based resume builder and parser. No sign-up, ATS-focused, and open source. **🟢 🆓 🌐 💼**
* [Resume Craft](https://resumecraft.org) — Inspired by OpenResume, runs client-side for full privacy. **🟢 🆓 🌐 💼**
* [Resumake](https://resumake.io) — Generates LaTeX-style PDFs from simple form inputs. **🟢 🆓 🌐**
* [ResumeLM](https://resumelm.com) — AI assistant, ATS checker, and cover letter generator. Free and open source. **🟢 🆓 🌐 🤖**
* [JSON Resume](https://jsonresume.org) — Open source initiative to create a JSON-based standard for resumes. **🟢 🆓 🌐 🛠**
* [CV Compiler](https://cvcompiler.com) — Tech resume analyzer and optimizer for software engineers. **🌐 🤖 💼**
* [Standard Resume](https://standardresume.co) — Clean, modern resume builder with beautiful templates. **🆓 🌐 💼**
* [Kickresume](https://www.kickresume.com) — AI-powered resume builder with ATS-friendly templates. **🌐 🤖 💼**

## 🖨️ Resume Rendering Engines

* [Typst](https://typst.app) — A modern markup-based typesetting system designed for scientific documents. **🟢 🌐 💻**
* [Pandoc](https://pandoc.org) — Universal document converter supporting multiple resume formats. **🟢 💻**
* [WeasyPrint](https://weasyprint.org) — Python library to convert HTML/CSS to PDF. **🟢 💻**
* [Prince](https://www.princexml.com) — Convert HTML to PDF with CSS support. **💻**
* [wkhtmltopdf](https://wkhtmltopdf.org) — Command line tool to render HTML into PDF. **🟢 💻**
* [Puppeteer](https://pptr.dev) — Node.js library for controlling headless Chrome to generate PDFs. **🟢 💻 🛠**
* [jsPDF](https://github.com/parallax/jsPDF) — Client-side JavaScript PDF generation. **🟢 🛠**
* [pdfkit](https://pdfkit.org) — PDF document generation library for Node and browser. **🟢 💻 🛠**
* [LaTeX](https://www.latex-project.org) — High-quality typesetting system for technical and scientific documentation. **🟢 💻**
* [XeTeX](http://xetex.sourceforge.net) — TeX typesetting engine with Unicode and modern font support. **🟢 💻**

## 🤝 Contributing

Your contributions are always welcome! Please take a look at the [contribution guidelines](CONTRIBUTING.md) first.

### How to Contribute

1. Fork this repository
2. Add your resource in the appropriate category
3. Ensure the link works and follows the format
4. Add appropriate legend icons (🟢 🆓 🌐 💻 🤖 💼 🛠 🎓 🎨)
5. Keep entries in alphabetical order within categories
6. Submit a pull request

### Quality Guidelines

* Resources should be actively maintained
* Links must be working and accessible
* Descriptions should be clear and concise
* Prefer open-source and free tools when possible
* Commercial tools should provide clear value
